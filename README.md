# Trainer Vox — установщики

Тренажёр для разучивания песен: ноты голоса из записи, текст с подсветкой, проход с оценкой.

Здесь только установщики для Windows — [последняя версия](https://github.com/DrBronsy/trainer-vox-releases/releases/latest).
Поставленное приложение само находит здесь новые версии и обновляется (Настройки → «Проверить обновления»).

- Windows 10 или 11, 64-бит; права администратора не нужны.
- Установщик не подписан: Windows скажет «Windows защитил ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
- При первом запуске приложение докачает Python, torch и модели (~12 ГБ на диске). Лучше с видеокартой NVIDIA:
  без неё всё работает, но подготовка песни в разы дольше.
